# Project tracking

The organization-level delivery record is maintained in [`project-delivery-status.md`](./project-delivery-status.md).

Use that record with:

- Linear project `github.com/zed-pkg`;
- Linear acceptance issue `DEN-2211` for the initial publication tranche;
- organization GitHub Projects `zed-pkg-project` and `zed-pkg-test-project`.

The default convention for another GitHub organization is a Linear project named `github.com/<organization>` and an organization project named `<organization>-project`. A documented shared-program boundary may map a test or certification organization into the product organization’s Linear program, as `zed-pkg-test` does here.

Implementation source, exact-head CI, retained artifact evidence, and merge commits remain in GitHub. Planning, ownership, dependencies, and acceptance remain in Linear.
